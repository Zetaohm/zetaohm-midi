| <a id="oq-ump-001"></a>OQ-UMP-001 | **How does the no_std crate meet the NFC rule for UMP text (REQ-TEXT-001)?**<br>M2-104-UM 1.8 says that text in UMP messages is UTF-8 in Unicode<br>Normalization Form C. Full NFC normalization needs Unicode composition<br>tables (tens of kilobytes of flash), which is a cost on bare-metal targets<br>(DEC-002). Options:<br><br>1. The crate normalizes text before it writes it (an NFC crate with<br>   `default-features = false`, or an optional `nfc` feature).<br>2. The crate does not normalize. Writers take `&str`, the API documents that<br>   the caller gives NFC text, and an optional feature gives a check<br>   (`is_nfc`) or normalization.<br>3. As 2, and the writer checks with a quick-check table only (Unicode<br>   NFC_Quick_Check), and rejects text that is not NFC.<br><br>Readers take the text as received in each case. | closed | [REQ-TEXT-001](../requirements/zmidi-ump.md#req-text-001) | [DEC-UMP-005](../decisions/zmidi-ump/DEC-UMP-005.md) |
| <a id="oq-ump-002"></a>OQ-UMP-002 | **What does the MDS Header field Number of Valid Bytes in This Chunk count?**<br>M2-104-UM 7.9 says the field "contains the size of this Mixed Data Set<br>Message Chunk in bytes including the header", that the number of Payload<br>UMPs follows from it, and that when it "is not an integer multiple of 16"<br>the sender pads the last Payload with zero bytes. 7.9.1 gives 16 for a<br>Header-only Chunk. Each Payload UMP has 2 prefix bytes (mt, group, status,<br>MDS ID) and 14 data bytes. Two readings:<br><br>1. The count is UMP bytes: 16 for the Header, and for each Payload UMP its<br>   2 prefix bytes and its data bytes, without the pad bytes. A chunk with<br>   L data bytes gives 16 + 2 * ceil(L / 14) + L. The "multiple of 16" pad<br>   rule matches this reading.<br>2. The count is 16 for the Header plus the data bytes only: 16 + L. Then<br>   the pad rule would need "multiple of 14", which the text does not say.<br><br>Reading 1 was chosen; see DEC-UMP-006 for the review of the<br>implementations. | closed | [REQ-MDS-001](../requirements/zmidi-ump.md#req-mds-001), [REQ-MDS-002](../requirements/zmidi-ump.md#req-mds-002) | [DEC-UMP-006](../decisions/zmidi-ump/DEC-UMP-006.md) |
