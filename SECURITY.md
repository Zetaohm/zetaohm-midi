# Security policy

## Supported versions

Only the newest release gets security fixes. While the version is 0.x, a fix comes in a new 0.x
release.

## Report a vulnerability

Do not open a public issue for a vulnerability. Use the private report of GitHub instead:
[Report a vulnerability](https://github.com/Zetaohm/zetaohm-midi/security/advisories/new).

Give the crate or package, the version, the input that causes the problem, and what happens (for
example a panic, a wrong result, or memory use without a limit). The readers of external data are the
most important: UMP, MIDI-CI, Property Exchange, Network MIDI 2.0, USB, BLE-MIDI, the MIDI file
readers and the C ABI.

You get an answer within 7 days. When a fix is ready, we publish it with a GitHub security advisory
and give you credit if you want it.
